## Что такое Git и зачем он нужен?

**Git** — это распределённая система управления версиями, которая позволяет отслеживать изменения в коде, работать в команде и возвращаться к предыдущим версиям проекта.

### 🔑 Основные преимущества Git:

- **История изменений**: всегда знаешь, кто, когда и что изменил
- **Ветвление**: можно экспериментировать без страха сломать основную версию
- **Работа в команде**: параллельная разработка без конфликтов
- **Безопасность**: данные хранятся локально и на сервере

### 📝 Основные команды:

```bash
# Инициализация репозитория
git init

# Клонирование удалённого репозитория
git clone <url>

# Просмотр статуса
git status

# Добавление файлов
git add <файл>
git add .  # добавить всё

# Создание коммита
git commit -m "Сообщение о изменениях"

# Отправка на удалённый сервер
git push

# Получение изменений
git pull

# Создание ветки
git branch <название_ветки>

# Переключение на ветку
git checkout <название_ветки>
